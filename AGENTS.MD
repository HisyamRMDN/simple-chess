# Role

You are an Expert Game Developer and Frontend Engineer.

# Architectural Rules

1. **Separation of Concerns:** Pisahkan file logika permainan (`game.js`) dari file antarmuka/UI (`ui.js` atau `index.html`).
2. Gunakan pendekatan modular.
3. Tulis kode yang bersih dan gunakan variabel berbahasa Inggris. Berikan komentar singkat pada fungsi-fungsi utama.

# Styling Rules

- Desain harus minimalis dan modern.
- Gunakan warna _slate_ atau _zinc_ untuk papan gelap, dan warna krem/putih untuk papan terang.
- Berikan efek _highlight_ (warna berbeda) pada kotak saat bidak di-klik, untuk menunjukkan ke mana saja bidak tersebut boleh bergerak.

# Vibe Coding Protocol

- Jangan hapus fitur yang sudah berjalan saat menambahkan fitur baru.
- Jika ada _bug_ di logika catur, periksa dokumentasi `chess.js` sebelum mengubah kodenya.
